# Modern Portfolio Template

![Next.js](https://img.shields.io/badge/Next.js-14-black) ![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue) ![Tailwind CSS](https://img.shields.io/badge/Tailwind-v4-cyan) ![GSAP](https://img.shields.io/badge/GSAP-3-green)

** is a premium, high-performance portfolio template designed for creative developers, agencies, and AI specialists. Built with the latest tech stack, it features cinema-grade animations, smooth scrolling, and a sophisticated monochrome aesthetic.

---

## ✨ Features

- **🎨 Premium Aesthetic**: Minimalist silver/white accents on a deep black canvas with noise textures.
- **🚀 AI-Native Messaging**: Pre-written copy tailored for AI developers and automation experts.
- **⚡ Performance First**: 100/100 Lighthouse scores, optimized images, and code splitting.
- **🌊 Smooth Scrolling**: Integrated **Lenis** for buttery smooth inertial scrolling.
- **🎭 Advanced Animations**: 
  - **GSAP ScrollTrigger** for scroll-driven reveals.
  - **3D Magnetic Tilt** profile cards.
  - **Text Scrambling** and **Spotlight** hover effects.
  - **Infinite Marquee** testimonials.
- **📱 Fully Responsive**: Flawless experience across mobile, tablet, and desktop.
- **📧 Contact Form**: Professional form with validation and direct email integration ready.
- **🛠 Modern Stack**: Next.js 14 (App Router), TypeScript, Tailwind CSS v4.

## 🎨 Customization

### 1. Personal Details
Edit `components/sections/Profile.tsx`, `Contact.tsx`, and `Footer.tsx` to update your name, bio, email, and social links.

### 2. Projects
Navigate to `components/sections/Projects.tsx` and update the `projects` array with your own case studies, links, and images.

### 3. Images
Place your images in the `public/assets` folder.
- `profile.png`: Your main profile photo.
- Project thumbnails: Add your project screenshots here and reference them in `Projects.tsx`.

### 4. Colors & Fonts
The template uses **Tailwind CSS v4**. 
- Global styles are in `app/globals.css`.
- Font settings are in `app/layout.tsx` (using `next/font/google`).
